## 🌐 About the Project

This repository documents practical exercises in cybersecurity footprinting and network discovery.

The project explores how network and domain information can be collected, analyzed, and interpreted using command-line and graphical security tools.

It includes practical command outputs, scan results, network topology documentation, and observations from the exercises.

## 🎯 Objectives

- Understand the fundamentals of footprinting and reconnaissance.
- Explore domain and DNS information.
- Identify network configuration details.
- Perform host discovery using Nmap.
- Visualize network discovery results using Zenmap.
- Understand the limitations of network scanning.

## 🔍 Practical Work

### 🌍 1. Domain Footprinting
**Tool:** WHOIS

Collected and examined domain registration information to understand domain ownership and registration details.

### 🛰️ 2. DNS Enumeration
**Tools:** NSLookup | DNSRecon

Explored DNS records and gathered domain-related information using DNS lookup and enumeration techniques.

### 🌐 3. Web Technology Analysis
**Tool:** WhatWeb

Identified web technologies and frameworks used by target websites.

### 📡 4. HTTP Header Analysis
**Tool:** cURL

Sent HTTP requests and examined response headers to understand server responses and web communication.

### 🛡️ 5. WAF Detection
**Tool:** Wafw00f

Performed web application firewall detection to identify potential WAF technologies.

### 🔎 6. Network Discovery
**Tools:** Nmap | Zenmap

Performed host discovery scans, reviewed scan results, exported XML output, and documented network topology.

📡 Network Discovery
The network discovery practical involved:
- Examining network configuration.
- Performing Nmap ping scans.
- Reviewing scan output in Zenmap.
- Exporting scan results in XML format.
- Documenting the observed network topology.
The practical report also discusses scan limitations and observations, including repeated MAC address values in the scan output.
📚 Key Learnings
- Understanding the reconnaissance phase of cybersecurity.
- Working with DNS and domain information.
- Using network discovery tools.
- Interpreting Nmap scan results.
- Understanding network topology.
- Documenting technical findings and limitations.
⚖️ Ethical Use
These exercises were conducted for educational purposes in an authorized environment.

Network scanning and reconnaissance should only be performed on systems and networks for which permission has been granted.
