## 🌐 About the Project

This repository documents practical exercises in cybersecurity footprinting and network discovery.

The project explores how network and domain information can be collected, analyzed, and interpreted using command-line and graphical security tools.

It includes practical command outputs, scan results, network topology documentation, and observations from the exercises.

## 🎯 Objectives

- Understand the fundamentals of footprinting and reconnaissance.
- Explore domain and DNS information.
- Identify network configuration details.
- Perform host discovery using Nmap.
- Visualize network discovery results using Zenmap.
- Understand the limitations of network scanning.
